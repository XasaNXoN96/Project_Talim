# Пошаговая проверка сайта руками

Для владельца. Цель: пройти все разделы сайта глазами разных ролей, отметить, что работает, и прислать мне замечания.
Время: примерно 1,5–2 часа. Можно по частям: каждая часть независима.

> Все данные в проверке **вымышленные** (названия начинаются с `DEMO` или «Namuna»). Реальные данные сотрудников и детей вводить нельзя, пока не пройден юридический чек-лист (`docs/LEGAL_AND_DATA_CHECKLIST.md`).

## 0. Подготовка (5–10 минут)

Откройте **PowerShell** и выполните по порядку (строки с `#` — комментарии, их вводить не нужно):

```powershell
cd C:\Users\Empire\Projects\Project_Talim
git pull origin claude/charming-feynman-3h7nwq
cd backend
Set-ExecutionPolicy -Scope Process Bypass
.venv\Scripts\Activate.ps1
```

**Один раз** откройте файл `backend\.env` (Блокнотом) и добавьте в конец строку:

```
DOCUMENT_SCAN_MODE=disabled
```

Зачем: на вашем компьютере нет антивируса ClamAV, а без него сайт (намеренно) отказывается принимать любые файлы. Эта строка отключает проверку **только для вашей локальной проверки**. На сервере её быть не должно.

Дальше:

```powershell
python manage.py migrate
python manage.py seed_roles
python manage.py seed_demo --yes
python manage.py runserver
```

`seed_demo --yes` создаёт демо-аккаунты и демо-данные. Команду можно запускать повторно: она добавляет только недостающее. На сервере она сама откажется работать.

Откройте в браузере `http://127.0.0.1:8000/`.

### Что лежит в демо-данных (после `seed_demo --yes`)
Всё вымышленное и нарисованное (настоящих фото и людей нет), чтобы вы увидели сайт «живым»:
* **8 учреждений** (школы, специализированная школа, детский сад, школа искусств, профессиональное училище) и около **25 сотрудников с портретами**;
* **13 новостей** (11 опубликованных с обложками, одна на проверке, одна черновик);
* **около 20 достижений**: медали, сертификаты, дипломы, награды; у каждого картинка-сертификат и фото, у трёх есть видео; ещё 2 на проверке, 1 на доработке, 1 черновик;
* **Галерея «Media»**: 16 фото (3 в черновике) и 3 видео;
* **8 документов** (PDF) в разных категориях;
* **около 13 заданий** (просроченные, срочные, выполненные), с комментариями и уведомлениями;

* **Отметки прихода и ухода** за последние дни у нескольких аккаунтов (часть «вне зоны»).
Команду можно запускать повторно: уже созданное не дублируется. Видео — короткие файлы (MP4/H.264) в `backend\apps\core\demo_assets\`.

### Как работать за двух людей сразу
Для сквозных сценариев нужны **два окна**: обычное окно браузера — для одного человека, **окно инкогнито** (Ctrl+Shift+N) — для другого. Так вы не будете выходить и входить заново.

### Язык и телефон
- Язык переключается кнопками **UZ / RU / EN** вверху. Для проверки удобнее **RU**.
- Вид на телефоне: нажмите **F12**, затем **Ctrl+Shift+M** и выберите ширину **390**.

### Письма
Письма (приглашения, сброс пароля) не отправляются, а **сохраняются файлами** в папке `backend\.dev_mail`. Последнее письмо:

```powershell
Get-ChildItem .dev_mail | Sort-Object LastWriteTime | Select-Object -Last 1 | Get-Content
```

   - [ ] Если выбрать школу, где директор уже есть (`DEMO 1-maktab`), — ошибка «в этом учреждении уже есть аккаунт директора».
3. На странице пользователя нажмите **«Отправить приглашение»**. Откройте последнее письмо (команда из раздела «Письма») и перейдите по ссылке внутри.

1. Администратор: **Задания** → «Новое задание». Название `DEMO: Проверка`, приоритет **«Срочное»**, срок: завтра, **время** 15:00. В поле «Образовательные учреждения» выберите `DEMO 1-maktab` и `DEMO 2-maktab`. Сохраните.

   - [ ] Если указать время без даты — ошибка.
2. Директор `demo_director1`: в «Уведомления» есть уведомление; в «Задания» задание со значком «Срочное» и сроком со временем.
3. Директор: откройте задание → «В работе» → «На проверке».
4. Администратор: откройте задание → «Выполнено».
   - [ ] При выборе двух школ создаются **два отдельных задания** (сайт показывает «Созданы задания: 2» и список заданий, которые вы выдали). У директора `demo_director2` своё задание осталось «Новое»: он его не брал в работу, а закрытие первого на нём не сказалось.

### Сценарий 3. Достижение с фото и видео (директор → администратор → сайт)
1. Директор `demo_director1`: **Достижения** → «Добавить достижение». Заполните, прикрепите 1–2 фото (любые JPG/PNG), в поле видео можно приложить небольшой MP4 или WebM, либо вставить ссылку `https://…`.
   - [ ] Без галочки «Согласие на публикацию» кнопка «Отправить на проверку» выдаёт ошибку.
2. После сохранения нажмите «Отправить на проверку». Теперь **изменить достижение нельзя**.
3. Администратор: уведомление «Достижение отправлено на проверку». Откройте достижение.
   - [ ] Нажмите «Вернуть на доработку» **без** комментария — ошибка; с комментарием — достижение вернулось директору, он видит комментарий и может править.

   - [ ] На предпросмотре нажмите «Сохранить как готовый черновик»: достижение остаётся закрытым (на сайте его нет).
   - [ ] Снова «Опубликовать» → предпросмотр → **«Подтвердить и опубликовать»**. Теперь достижение видно гостю на `/yutuqlar/` и в блоке главной.
   - [ ] Измените название после предпросмотра и сразу нажмите «Подтвердить»: сайт откажет и попросит открыть предпросмотр заново.

### Сценарий 4. Правка своих данных с подтверждением (сотрудник → кадры)
1. `demo_employee`: «Моя карточка» → «Изменить мои данные». Измените рабочий телефон и отправьте («Отправить на подтверждение»).

2. `demo_hr`: Сотрудники → «Запросы на изменение». Откройте запрос: видно «было → стало».
   - [ ] «Отклонить» без причины — ошибка. С причиной — сотрудник видит причину на своей странице.
3. Отправьте ещё один запрос и **подтвердите** его кадрами: телефон в карточке изменился.
   - [ ] После решения в запросе **нет** старых и новых значений (стираются).
4. Если HR подаёт запрос о **своих** данных, подтвердить его сам не может (сообщение об этом).

## 9. Что известно и не считается ошибкой
- Разделы **«Приход и уход»** и **«Геолокация»** — образцы (ждут юридического решения).
- Публичные блоки с пометкой «Макет» (цифры, объявления, документы, карта, адрес и телефон в подвале).
- Нет публичных страниц «Образовательные учреждения» и «Учителя» (в меню они ведут к блокам главной).
- Нет поиска на публичном сайте.
- Видео с телефона (H.264) в некоторых браузерах без нужного кодека не играет; в Chrome, Safari и Edge должно играть.
- Чат без файлов и без обновления в реальном времени: страница обновляется кнопкой «Обновить».
