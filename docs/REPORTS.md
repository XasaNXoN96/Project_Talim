# Отчёты и аналитика (День 6)

Страница `/portal/reports/` и экспорт `/portal/reports/export/xlsx|pdf/`. Все цифры считаются из PostgreSQL при каждом открытии; демонстрационных чисел нет.

## Показатели
Активные сотрудники (статус «Faol»; всего — без архива); сотрудники по подразделениям и должностям; задания по статусам; завершённые, просроченные (открытые со сроком в прошлом) и выполненные с опозданием; выполнение по подразделениям и (при праве) по исполнителям; документы по категориям и периодам; динамика «создано / завершено» по дням, неделям или месяцам (по умолчанию выбирается автоматически).
Определения: набор заданий — созданные в выбранном периоде; «завершено в периоде» — по дате закрытия. Задание с несколькими исполнителями в итогах считается один раз, а в разрезе подразделений/исполнителей — для каждого исполнителя (указано в примечании к таблицам).

## Фильтры
Дата с/по (по умолчанию последние 30 дней; максимум 366 дней), подразделение (включая подчинённые), статус задания, категория документов, группировка. Неверные фильтры (даты наоборот, слишком длинный период, чужое подразделение, мусор) → сообщение об ошибке и **никаких данных**; экспорт при неверных фильтрах файл не создаёт.

## Права (проверяются на сервере; одна функция `build_report` кормит и страницу, и оба экспорта)
| Право | Что даёт | Роли |
|---|---|---|
| `reports.view_reports` | страница; **область** берётся из области роли (вся организация / подразделение с подчинёнными) | руководитель подразделения (своя ветка), кадры, администратор |
| `reports.export_reports` | Excel и PDF (те же фильтры и область) | те же |
| `reports.view_report_people` | таблица «по исполнителям» (имена + результаты) | руководитель (только своя ветка), администратор. **Кадры — нет** |
Остальные роли (сотрудник, контент-менеджер, системный администратор) — 403 на странице и в экспорте. Документы считаются только среди тех, что пользователь вправе открыть (`visible_documents`): конфиденциальные и чужие подразделения в счётчики не попадают. Раздел документов скрыт без права `documents.view_document`. Просмотр таблицы по исполнителям и каждый экспорт пишутся в аудит (фильтры, формат, число строк; без имён и данных).

## Экспорт и защита от большого объёма
- Excel: `openpyxl`; PDF: `reportlab` со встроенным шрифтом DejaVu Sans (лежит в `backend/assets/fonts/` с лицензией) — кириллица и узбекские буквы (ў, ғ, қ, ҳ, ʻ, ‘ ’) проверены тестами; PDF не зависит от шрифтов сервера.
- Лимиты: период ≤ 366 дней; ≤ 500 строк на таблицу (Excel и экран), ≤ 60 в PDF; остаток обозначается «ещё N строк». Эти значения — `REPORT_MAX_*` в настройках.
- Защита от формул в Excel: текст, начинающийся с `= + - @`, записывается как текст с префиксом `'`.
- В файлы не попадают контакты, личные данные, секреты; ответы с `Cache-Control: private, no-store`.

## Зависимости (закреплены с хэшами)
Добавлены `openpyxl 3.1.5` (+`et-xmlfile`) и `reportlab 4.5.1` (+`pillow`, `charset-normalizer`). Прежние закрепления не менялись. Pillow и reportlab — самые крупные новые поверхности атаки (разбор изображений не используется, но библиотека установлена): следить за обновлениями безопасности.

## Интерфейс
Дизайн-система проекта (карточки, KPI, таблицы); столбики динамики — на CSS без внешних библиотек и без встроенных скриптов (CSP не менялась). Состояния: пустой результат («ma’lumot yo‘q»), ошибка фильтров, ошибка построения (страница-заглушка без трассировки, статус 500), «Tayyorlanmoqda…» на кнопках экспорта.
**Локализация (с Дня 7):** страница, Excel и PDF — на узбекском, русском и английском по выбранному языку пользователя (см. [LOCALIZATION.md](LOCALIZATION.md)); названия листов и заголовки Excel/PDF переведены, цифры одинаковы во всех языках.
Проверено в настоящем браузере (Chromium, CSP включена) на 1440 и 390 px: нарушений CSP нет, горизонтальной прокрутки страницы нет; пятиколоночная таблица «по подразделениям» на узкой карточке прокручивается внутри карточки.

## Ограничения
Отчёты строятся «вживую» без кэша (при росте данных потребуется индексация/кэш); нет отчётов по посещаемости и чату (модулей нет); PDF — табличный, без графиков; в Excel нет диаграмм.
