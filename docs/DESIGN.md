# Дизайн сайта (обновлённый)

Новый вид сайта собран поверх прежней дизайн-системы без переписывания страниц: цвета, шрифты, скругления и главные блоки переопределены в одном файле. Старый файл `assets/css/styles.css` не менялся.

## Где что лежит
| Что | Файл |
|---|---|
| Весь новый стиль (цвета, шрифты, шапка, главная, вход, кабинет, адаптивность) | `backend/static/css/theme.css` |
| Шрифты (свои, с нашего сервера, без Google) | `backend/static/fonts/` (Manrope — текст, Literata — заголовки; поддерживают узбекский (латиница), русский и английский) |
| Узор в виде восьмиконечной звезды | `backend/static/img/ornament.svg`, `ornament-dark.svg` |
| Логотип-заглушка (звезда в круге) | `backend/templates/includes/logo.html` |
| Главная страница | `backend/templates/content/home.html` |
| Шапка и подвал сайта | `backend/templates/base_public.html` |
| Боковая панель и верх кабинета | `backend/templates/base_portal.html` |
| Страница входа (правая тёмная часть) | `backend/templates/includes/login_art.html` |

## Палитра
Тёплый бумажный фон `#fbf9f4`, тёмно-синие чернила `#12263f` (шапка, подвал, боковая панель), бирюзовый `#0f766e` для главных кнопок и ссылок, золотой `#c8921b` / `#f3d58a` для наград и акцентов. Цвета заданы переменными в начале `theme.css` (`--brand-*`, `--navy-*`, `--gold*`): достаточно поменять их, и сайт перекрасится целиком.

## Экраны и ширины (проверено)
| Устройство | Ширина | Что происходит |
|---|---|---|
| Телефон | 360–480 | меню-«бургер», плитки в 2 колонки, кнопки на всю ширину, боковая панель кабинета выезжает слева, таблицы превращаются в карточки |
| Планшет | 600–1099 | меню-«бургер», боковая панель кабинета сужена до значков, главный блок в одну колонку |
| Ноутбук | 1100–1599 | полное меню, 5 плиток в ряд |
| Большой монитор | 1600–2399 | контейнер шире (до 1380–1560 px) |
| 4K / очень большой | от 1920 | интерфейс пропорционально увеличивается (`zoom`), чтобы текст не казался мелким |

На всех этих размерах горизонтальной прокрутки нет, ошибок политики безопасности (CSP) нет, шрифты загружаются с нашего сайта.

## Что пока заглушка
- Фото в главном блоке главной страницы (иллюстрация здания): заменить настоящей фотографией, когда будет согласована.
- Логотип: временный знак; настоящий герб или логотип отдела нужно получить у заказчика.
- Блоки с пометкой «Maket» на главной (цифры, объявления, образцы документов) заполняются реальными данными.
